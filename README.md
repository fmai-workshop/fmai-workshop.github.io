# fmai-workshop.github.io

Legacy redirect for the workshop's old URL. The workshop was renamed from
**FMAI** to **FAGEN** and moved to:

→ <https://fagen-workshop.github.io/>

This repository only contains a static redirect page (`index.html`) and a 404
fallback (`404.html`). Both preserve the requested path, query string, and
fragment, so deep links like `https://fmai-workshop.github.io/papers/` land at
`https://fagen-workshop.github.io/papers/`.

All workshop content lives in
[FAGEN-workshop/fagen-workshop.github.io](https://github.com/FAGEN-workshop/fagen-workshop.github.io).
